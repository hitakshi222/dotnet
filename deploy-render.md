# Deploy the full app to Render

The Render Blueprint in `render.yaml` deploys the React frontend, .NET API,
and PostgreSQL database in Oregon. It uses Render's free plans for a test
deployment.

## Create the services

1. Push the deployment files to the repository's `main` branch.
2. In Render, choose **New → Blueprint** and select `hitakshi222/dotnet`
   on the `main` branch.
3. Review the services from `render.yaml` and apply the Blueprint.
4. Wait for the database and both services to finish deploying. The API
   initializes a new empty database with `postgres/schema.sql` and
   `postgres/seed.sql` on its first start.
5. Open the `campusdesk-frontend` static site URL. The frontend gets the
   API hostname from the Blueprint and uses HTTPS.

The API and database use the same Render region and the database's internal
connection details. Database credentials are generated by Render and are
not stored in this repository.

## Free-plan limitations

This configuration is for testing, not production. Render's free web service
can spin down when idle, so the first request can take about a minute. The
free PostgreSQL database expires 30 days after creation; export the data or
upgrade the database before then if you need to keep it. See
[Render's free instance limits](https://render.com/docs/free).
